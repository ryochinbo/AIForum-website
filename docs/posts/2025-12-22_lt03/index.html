第3回 LT会

第3回 AIForum LT会を開催しました。今回は2件のライトニングトークが行われました。

LT① ExcelにLLM APIカスタム関数を組み込んだ業務自動化

ExcelのVBAやOffice Scriptsを使ってLLMのAPIを呼び出すカスタム関数を作成し、Excel上での処理を自動化するアプローチを紹介しました。

  • LLM APIをExcel関数として呼び出す仕組みの作り方
  • セルの値をプロンプトに組み込んで一括処理する実装例
  • 文章要約・分類・翻訳などをExcel内で完結させるデモ

LT② ローカルで動くRAGの自作方法

社外秘データを扱う場合に有効な、完全ローカル環境で動作するRAG（Retrieval-Augmented Generation）システムの自作方法を紹介しました。LLM自体はAPI経由で利用します。

  • RAGの基本構成（ドキュメント読み込み → ベクトル化 → 検索 → 生成）
  • ローカルで動くベクトルDBの選定と構築方法
  • LLM APIと組み合わせたクエリ応答フローの実装例
